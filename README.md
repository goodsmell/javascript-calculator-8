# javascript-calculator-precourse

# 문자열 덧셈 계산기

---

💪🏻 목표 : 입력한 문자열에서 숫자를 추출하여 더한다.

</br>

## 📝 기능 요구사항

> 입력 : `구분자`와 `양수`로 구성된 `문자열` </br>
> 출력 : 덧셈 결과 ex) `결과 : 6` </br>

### ✔️ 기본 동작

> ✔️ `,(쉼표)`와 `:(콜론)`을 `기본 구분자`로 하여 분리한다.</br>
> ✔️ 문자열 앞부분의 `//`와 `\n` 사이에 위치하는 문자를 `커스텀 구분자`로 사용 한다</br>
> ✔️ 잘못된 값을 입력할 경우 `[ERROR]`로 시작하는 메시지와 함께 `Error를 발생`시킨 후 `애플리케이션은 종료`

</br>
</br>

## ✨ 구현 기능 목록

1. 사용자는 문자열을 입력한다.
2. 사용자가 아무 입력도 하지 않으면 결과는 0으로 출력된다.
3. 사용자는 커스텀 구분자를 설정할 수 있다.
   - 커스텀 구분자 헤더를 감지한다. (`//...\n`)
   - 커스텀 구분자를 추출한다.
4. 사용자는 양수와 허용된 구분자만 입력할 수 있다.
   - 허용 문자 검증: 양수, 기본 구분자(쉼표`,` / 콜론`:`), 커스텀 구분자
5. 구분자로 구분된 숫자들을 모두 더한 결과를 출력한다.

</br>
