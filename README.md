# javascript-calculator-precourse

# 문자열 덧셈 계산기

---

💪🏻 목표 : 입력한 문자열에서 숫자를 추출하여 더한다.

</br>

## 📝 기능 요구사항

> 입력 : `구분자`와 `양수`로 구성된 `문자열` </br>
> 출력 : 덧셈 결과 ex) `결과 : 6` </br>

> ✔️ `,(쉼표)`와 `:(콜론)`을 `기본 구분자`로 하여 분리한다.</br>
> ✔️ 문자열 앞부분의 `//`와 `\n` 사이에 위치하는 문자를 `커스텀 구분자`로 사용 한다</br>
> ✔️ 잘못된 값을 입력할 경우 `[ERROR]`로 시작하는 메시지와 함께 `Error를 발생`시킨 후 `애플리케이션은 종료`

</br>
</br>

## ✨ 구현 기능 목록

1. 문자열 입력 받기
2. 입력 값 예외 처리
3. 숫자 추출하기
4. 숫자 더하기
5. 덧셈 결과 반환하기

</br>

## 🚨 입력 예외 처리 목록

| 처리현황 | 예외 사항                                         | error message                                                                                          |
| -------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
|          | 커스텀 구분자, 기본 구분자, 숫자 이외의 문자 포함 | [ERROR] 올바르지 않은 입력입니다. (커스텀 구분자 또는 ,(쉼표)와 :(콜론) 그리고 숫자만 입력가능합니다.) |
|          | 0 포함                                            | [ERROR] 양수로 구성된 문자열만 입력 가능합니다. (0은 양수가 아닙니다)                                  |
